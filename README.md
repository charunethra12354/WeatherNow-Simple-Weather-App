🌦️ WeatherNow – Simple Weather App

📖 About the Project

WeatherNow is a simple weather application that helps users check weather information for different cities. It is designed with a clean and user-friendly interface.

🎯 Objectives

- Display weather information for a selected city.
- Show temperature and weather conditions.
- Provide a simple and easy-to-use interface.
- Help users check weather information quickly.

✨ Features

- 🌍 Search weather by city name.
- 🌡️ Display temperature.
- ☁️ Show weather conditions.
- 📱 Simple and user-friendly design.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

📂 Project Structure

WeatherNow-Simple-Weather-App/
├── index.html
├── style.css
├── script.js
└── README.md

🚀 How to Use

1. Open the WeatherNow application.
2. Enter a city name.
3. Click the Search button.
4. View the weather information.

📸 Sample Output

       WeatherNow 🌦️

   Enter City: Coimbatore

       Temperature: 28°C
       Condition: Cloudy

Note: The values above are illustrative sample data, not live weather information.

🔮 Future Improvements
